# MOBA Prototype (Unity 6)

Учебный прототип игры в жанре MOBA. Разработан с учетом обратной связи от ревьюера.

## 🎮 Управление
* **Левая кнопка мыши (ЛКМ)** — движение персонажа по арене.
* **Правая кнопка мыши (ПКМ)** — выстрел снарядом в сторону курсора (с кулдауном 0.3 сек).
* **Клавиши WASD** — альтернативное прямое управление персонажем.

## ⚙️ Логика игры
* **Цель:** Уничтожить красную базу врага.
* **Враги (Enemy):** Волны красных врагов спавнятся с 3 разных точек. Если игрок подходит близко, враги переключаются на него и пытаются убить, а затем идут атаковать вашу базу.
* **Союзники (Peasant):** Синие крестьяне пытаются добраться до вашей базы, чтобы укрыться в ней. При достижении базы они исчезают.
* **Дружественный огонь:** Если вы выстрелите в своего крестьянина, он погибнет, экран мигнет красным, а вы получите штраф — невозможность стрелять в течение 3 секунд.
* **Здоровье игрока:** Игрок получает урон от врагов. Если здоровье упадет до 0 — наступает поражение.
* **Лечение:** При нахождении рядом с синей базой здоровье персонажа восстанавливается.
* **Победа/Поражение:** Уничтожение базы врага приносит победу. Уничтожение вашей базы врагами или смерть игрока — поражение.

## 🛠 Технические детали и исправления (по замечаниям ревьюера)
* **Движок:** Unity 6 (6000.0.29f1).
* **Навигация:** AI Navigation (NavMesh) с настройкой плавности (Acceleration, Angular Speed).
* **Ввод:** Новый Input System (Mouse.current, Keyboard.current) с проверкой на null для безопасного запуска.
* **Стрельба:** Направление снаряда зависит от позиции курсора, добавлен кулдаун и штраф за дружественный огонь.
* **Атака врагов:** Враги останавливаются на дистанции (Stopping Distance) и наносят урон базе через скрипт (без физического столкновения).
* **UI:** Адаптивный Canvas Scaler. Кнопка и текст привязаны к центру экрана (Anchor Presets). Экран мигает при дружественном огне.
* **Визуал:** Базы сделаны полупрозрачными для лучшего обзора.

## 📝 Отступления от базового задания и дополнительные механики
* **Союзные крестьяне (Peasant):** Добавлена механика спасения союзников, которые пытаются добраться до базы.
* **Дружественный огонь:** Добавлен штраф за убийство союзника (невозможность стрелять 3 секунды и визуальная вспышка экрана). Это усложняет геймплей и заставляет игрока быть аккуратным.
* **Погоня за игроком:** Враги при приближении к игроку переключают цель с базы на него, что делает бой более динамичным.
* **Кодировка и настройки:** Проект использует кодировку UTF-8. Для единообразия настроек редакторов добавлен файл `.editorconfig`.
