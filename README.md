# MOBA Prototype (Unity 6)

Учебный прототип игры в жанре MOBA. Реализован в рамках домашнего задания.

## 🎮 Управление
* **Левая кнопка мыши (ЛКМ)** — движение персонажа по арене (указатель мыши).
* **Правая кнопка мыши (ПКМ)** — выстрел снарядом в направлении взгляда.

## ⚙️ Логика игры
* **Цель:** Уничтожить красную базу врага (Enemy Base), стреляя по ней снарядами.
* **Угроза:** Красные враги (Enemy) автоматически идут к вашей синей базе и атакуют её.
* **Лечение:** Если подойти к своей синей базе, здоровье персонажа восстанавливается.
* **Проигрыш:** Если враги уничтожат вашу базу, появляется экран поражения.
* **Победа:** Если вы уничтожите базу врага, появляется экран победы.

## 🛠 Технические детали
* **Движок:** Unity 6 (6000.0.29f1).
* **Навигация:** AI Navigation (NavMesh).
* **Ввод:** Классический Input Manager.
* **Интерфейс:** UI Canvas с экранами победы/поражения и кнопкой перезапуска.
